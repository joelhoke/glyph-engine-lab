# Hero previews

Transparent snapshots of the actual homepage model renderers, in their resting
poses. Each theme downloads five WebP images totaling about 43 KiB. The fixed
600 × 400 viewport matches the live renderer's 3:2 local box; outer CSS positioning
and mobile carousel transforms apply equally to the image and canvas.

Regenerate against a running local preview:

```sh
node scripts/dev/capture-hero-posters.cjs http://localhost:3000
```

The corresponding model credits remain in the site's Credits section and in
`../models/*/license.txt`. These images are derived from those same assets.

About uses the user-supplied family artwork at
`/assets/about-light-study/placeholder.webp`. Its HTML heading remains visible
until the live scene renders; this placeholder is not generated by the capture scripts.

Vibe and Gallery also have `*-section-*` previews with their actual section
poses. Regenerate these with `scripts/dev/capture-section-posters.cjs`. Section
images load lazily and use `object-fit: cover` to preserve the renderer's fixed
vertical field of view when the containing box changes aspect ratio.
